# Маршрутный лист из выгрузки

Статический сайт: загружаете выгрузку заданий (.xlsx с колонками «Адрес задания», «Номер задания», «Исполнители», «Дата выполнения») — получаете заполненный «Отчёт о служебных поездках» (4 раздела, как в шаблоне).

Что делает:
- выбирает задания нужного сотрудника за нужный месяц;
- раскладывает их по дням в порядке времени выполнения;
- добавляет в каждый день выезд с базы (0 км) и возврат на базу;
- километры: вручную (запоминаются для пар адресов) или автоматически по дорогам через OpenStreetMap (Nominatim + OSRM);
- считает сумму по тарифу за 1 км и скачивает .xlsx с формулами.

Все данные обрабатываются в браузере, на сервер ничего не отправляется (кроме адресов — в OpenStreetMap, только при нажатии «Посчитать км автоматически»).

## Запуск

Откройте `index.html` через любой статический сервер, например `python3 -m http.server`, или включите GitHub Pages (Settings → Pages → Deploy from branch).
